# 0.2.0-alpha.1 验收与限制

2026-10-06，本地最终版本的 Python 回归为 **626 项通过**，浏览器插件与 Markdown/状态渲染测试合计 **28 项通过**。测试包含权限、版本、幂等、引用、可见失败、过期状态、维护修订及备份恢复。

实际容器检查涵盖非 root、只读根文件系统、最小能力、令牌权限、401/403、中文知识新增/修订/过期、幂等重放和冲突、历史分页，以及重启后的数据与令牌保留。镜像包含 Linux AMD64 和 ARM64；ARM64 在本机容器实际运行，AMD64 通过兼容执行完成中文笔记写入检查，未在独立 AMD64 宿主做性能验收。

通过认证异步采集接口读取了 [Python 中文公开文档](https://docs.python.org/zh-cn/3/tutorial/introduction.html)，任务到达 complete，保存约1.2万字符的 Markdown，随后精确读取同一版本。这验证公开 HTML 采集与容器持久存储，不证明公众号、视频或任意反爬服务可读取。

真实浏览器检查了 360、390、768、1440 四种宽度，未发现横向溢出或表单控件越界；修改后的笔记/来源阅读、修订层原图、历史原文、自动整理禁用与维护提示另行检查。页面使用真实程序。30秒1080p展示视频使用独立虚构资料，已独立审查；手机窗口可能无法阅读截图内所有小字。

完整备份测试包括：备份后删除原库、恢复笔记修订与来源覆盖层、保留过期状态及原始读取响应、重新生成 Obsidian 镜像。篡改正文、元数据、证据或维护链会被拒绝。生成的 Obsidian 镜像和向量缓存可再生；备份不包含服务密钥和网关令牌。实际升级仍应先在隔离卷恢复验证。

嵌入/重排的中文 Hit@2、Recall@2、MRR@2 均为1.0，来自四份固定向量示例，只验证实现链路，不能作为生产模型效果。Laya 六例正确五例，存在路由器文章误分类，本版未启用它。详细例题与原始短例响应见[检索与分类评估](检索与分类评估.md)。

本版面向单用户本机使用。微信消息桥需要另行部署；公众号与视频依赖配置服务。手写笔记可检索并供智能体读取，自动兴趣与 Wiki 仍以采集原文为证据。模型输出质量、语义召回、真实第三方读取/搜索服务以及完整业务工作流需按用户实际资料独立验收。
