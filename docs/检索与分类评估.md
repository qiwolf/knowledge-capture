# 可选检索与分类：配置、证据和边界

当前系统以关键词检索作为基础。嵌入和重排均为可选项；用户没有启用时不会调用这些服务。Laya 尚未接入采集、知识状态或检索决策，不会自动修改标签、删除正文或丢弃资料。

## 嵌入与重排怎么配置

设置中的两个可选服务分别填写启用状态、完整接口地址、模型名称和密钥。完整接口地址示例为 `https://<服务地址>/v1/embeddings` 或 `https://<服务地址>/v1/rerank`，系统不会猜测路径。密钥保存在受保护的本机设置文件中，公开设置只返回“已配置”状态；更换服务地址的来源主机或端口不会沿用旧密钥。公网使用 HTTPS，私网 IP 或 localhost 可使用 HTTP。

嵌入固定采用 OpenAI compatible embeddings 协议：请求包含 `model`、`input` 和 `encoding_format: float`；响应为带对应 `index` 和 `embedding` 的 `data` 数组。每批响应必须完整、向量数值有限、维度一致。

重排固定采用 Cohere/Jina compatible rerank 协议：请求包含 `model`、`query`、`documents`、`top_n`；响应为包含 `index` 和 `relevance_score` 的 `results`。它仅对本次已检索的最多 100 个候选排序，不能引入新的知识 ID 或链接。缺项、重复索引、越界或非有限分数会触发降级。

工作台保存操作为 `settings-retrieval`，参数为 `kind`（`embedding` 或 `rerank`）、`endpoint`、`model`、`api_key`、`enabled`，以及可选的 `clear_key`。保存本身不发模型请求；配置嵌入后需要显式构建索引。

## 索引与失效处理

来源原文和人工、智能体维护的知识使用同一个知识库。已有来源的修订层和原文共用知识 ID；检索只返回该 ID 的当前有效内容，不会在修订层过期后偷偷退回原文。默认排除过期记录，结果保留精确知识 ID、版本、原文引用及修订层是否落后于来源的信息。

向量索引按服务地址、模型名称和协议区分空间，并记录维度、知识版本、内容哈希和分块。文本完整分块，保留末尾，不只索引开头。建索引全部完成并再次确认知识版本没有变化后才发布新代际。失败不会替换上一完整代际；改变模型身份不会混用旧空间。相同模型名称背后的服务权重若被服务端替换，本系统不能自动证明其未变，维护者应重建索引并重新做实际模型验收。

查询会过滤版本或内容哈希不匹配的旧向量。未配置、索引缺失、维度变化、嵌入失败或重排失败均有明确状态；可选服务失败仍保留关键词结果。启用混合检索时使用关键词和向量候选融合，最多保留 100 个候选，并公开候选上限和是否可能截断。未启用可选服务时保留关键词分页。

相似分数表示候选排序依据，不表示事实正确、证据充分或已经审校。原文、修订记录和固定版本引用才是后续核查入口。

## Laya 实际接口小样本

通过内网服务只读检查，`GET /v1/models` 返回 `multilingual` 及 `laya-multilingual` 别名。决策使用 `POST /v1/systemone`；该路径的 GET 返回 404，不意味着 POST 不可用。请求采用 `state` 和按名称组织的 `questions`，本次问题类型为 `choice`，包含分类说明与候选类别。协议参考[上游 HTTP API 文档](https://github.com/NandhaKishorM/laya/blob/main/docs/http-api.md)。

实际发送了六条人工构造的公开主题中文短样例，不含业务私密资料。六次 HTTP 均为 200，但分类只有五次正确，不能把 HTTP 成功当成语义正确。

| 样例主题 | 预期 | 实际 | 服务 confidence |
| --- | --- | --- | ---: |
| 路由器固件升级、备份、回滚 | 信息技术运维 | **访问拦截，误分** | 0.1235 |
| 长护险经办、失能评估、护理服务 | 长护险 | 长护险 | 0.9736 |
| 医院运维服务采购与验收 | 医院采购 | 医院采购 | 0.8686 |
| 番茄炒蛋做法 | 其他 | 其他 | 0.7896 |
| 验证码拦截，没有文章正文 | 访问拦截 | 访问拦截 | 0.9250 |
| 医院场景下的路由器技术维护 | 信息技术运维 | 信息技术运维 | 0.6762 |

服务报告首例推理延迟约 944.7 毫秒，其余五例约 35.4–40.7 毫秒。该小样本不足以评价并发能力或稳定性能；confidence 也没有在本地业务集上校准。

纯运维文章被误分为访问拦截，意味着当前不能用它自动判断正文无效或丢弃采集。未来可评估影子标签：仅记录模型建议和分数，与人工标签比较，不影响正文、来源、知识状态或自动采集。即使使用置信度门槛，也需要独立验证，不能由这六例推定安全阈值。

当前**没有启用 Laya 自动决策或影子分类**。原始请求与响应保留在[脱敏小样本记录](evaluation/laya-public-chinese-smoke.json)中；未修改远端服务配置。

## 维护知识与原文证据的边界

新增笔记和来源修订层可通过统一知识接口及检索读取，但它们属于人工或智能体维护的知识，**当前不会自动冒充已采集原文进入旧版整理、兴趣推断或 Wiki 引用**。若要将这些内容纳入新的证据体系，需要另行建立明确的引用类型和审核流程。

已有来源被标记过期后，旧版原文检索和自动整理通路也会停止把它当作当前有效证据；存在正文或标题修订、或修订层落后于已更新来源时，同样不会绕回原文继续自动生成结论。仅增加标签、且正文、标题与当前来源一致的有效覆盖层不影响原文证据使用。引用不会被偷偷替换为修订层文字。

历史原文、整理和 Wiki 仍可读取。接口将维护状态及当前证据有效性单独返回；源文件是“最新采集版本”不代表它仍是当前有效知识。受影响的既有 Wiki 标记为 `stale` 和 `needs_review`，保留原引用等待核实，不删除历史材料。

背景关联提醒采用相同门禁：自动扫描跳过不可用来源，显式指定不可用来源会被拒绝；历史提醒仍可查看原证据，但会标记过时、停止作为可操作的当前提醒，并返回所引用知识的维护状态。
