# Chrome / Edge 采集插件

首版 Manifest V3。只把当前标签或右键选中的链接及可选备注发送给你配置的个人采集服务，不读取微信聊天、不注入网页脚本、不复制浏览器 Cookie。公众号等需要登录的内容仍可能采集失败。

## 本地加载

1. 启动项目的采集服务，取得访问令牌。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选择本 `extension` 目录。
4. 打开插件的“服务设置”，填写服务根地址（默认 `http://127.0.0.1:8765`）与令牌，点击“保存并授权连接”，同意该服务地址的访问权限。
5. 在普通网页点击插件，选填备注后提交。也可右键网页链接，选择“添加到知识采集”。右键提交不附备注。
6. 弹窗显示最后一个任务的 ID 和状态；点击“刷新状态”查询。右键的错误可在弹窗查看。插件不自动轮询。

“已接收，等待采集”仅表示服务创建任务。只有服务状态 complete 才显示“采集完成”；partial 明确表示部分完成。提交结果不明时不自动重试，先核实后台记录避免重复。

令牌仅存于 chrome.storage.local，未加密、不跨设备同步。不应在共用浏览器配置中保存。远程地址要求 HTTPS。插件只申请配置的服务 origin 权限，不需要全站读取授权；更换地址时移除旧地址授权。设置保存成功不表示服务连接验证通过。

## 后端接口

- `POST /api/captures`，Bearer 认证，JSON `{url,note,origin:"user"}`；预期 HTTP 202 `{id,status}`；任务可能已从 queued 进入 running、complete、partial 或 failed。
- `GET /api/captures/<id>`，Bearer 认证；预期 `{id,status}`，状态 queued/running/complete/partial/failed。

## 验证

在本目录运行 `npm test`，使用 Node 自带测试器，不安装依赖。测试覆盖地址/协议约束、认证位置、响应校验、提交不重试、权限和 CSP 基础结构。静态测试及模拟网络测试不等于已在真实 Chrome/Edge 完成验收。

真实浏览器仍需验证：加载无错误；设置权限只申请服务地址；普通网页提交与右键提交；服务任务与原文一致；关闭服务、错误令牌、部分采集失败可见；内部页面无法采集；键盘 Tab 焦点与状态朗读；关弹窗再打开仍保留任务；重新启动浏览器后 worker 能处理。
